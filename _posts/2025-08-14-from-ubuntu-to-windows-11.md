---
title: "From Ubuntu to Windows 11"
tags: [thoughts]
---

Being an Ubuntu enthusiast for a long period of time, I'm now sort of forced to use Windows 11. The reason - my tools like Unity, Android Studio, and .NET all run better on Windows. Gaming is also a big thing for me, and despite all the progress in Unix compatibility, Windows remains the go-to platform for it. And I must say, yes there's some tension, but overall it's not too bad. I even like it. Especially paired with Ubuntu on WSL2 where I run all the familiar tools. And I'm still running Ubuntu on my other laptop.
