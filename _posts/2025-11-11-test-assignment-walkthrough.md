I'm sharing, with permission from the company, a walkthrough presentation of a recent developer test assignment - a React project built for a front-end role application. The video covers the project's component structure, testing approach, and accessibility features. Development and presentation together took about eight working hours.

<p><strong>Key highlights:</strong></p>
<ul>
  <li>Next.js Pages Router with TypeScript</li>
  <li>Component reusability and clear hierarchy</li>
  <li>Unit tests with Vitest</li>
  <li>Accessibility-first design (WCAG 4.5:1 contrast, keyboard navigation, ARIA tags)</li>
  <li>Full walkthrough of architecture decisions</li>
</ul>
